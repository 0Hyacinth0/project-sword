# 内嵌战斗台 UI 改造设计

## 背景

当前战斗体验有两个核心问题：

- 战斗通过独立 `/battle` 路由打开，会从首页三栏主界面中硬切出去，角色、背包、队伍和副本上下文中断。
- 战斗 UI 更像调试页面，敌我排布、行动按钮、日志和结算层级缺乏现代网游界面的聚焦感。

本轮只改前端 UI、路由交互和组件结构，不改后端接口、数据库或服务器配置。

## 目标

- 将战斗从独立跳转模式改为首页中栏内嵌模式。
- 重做战斗主视觉，采用“焦点目标 + 两侧队列”的现代网游战斗排布。
- 保留现有战斗状态机、行动提交、Boss 机制、副本结算和 Mock 数据流。
- 移除入口测试页心智，让战斗成为地图、副本、多人房间中的自然内嵌状态。

## 非目标

- 不重写战斗引擎。
- 不新增后端接口。
- 不重做角色、背包、地图、副本、组队的业务逻辑。
- 不加入新的第三方 UI 库。

## 交互设计

首页中栏新增 `battle` 视图。野外遭遇、副本进入、多人副本开始挑战后，不再 `router.push({ name: 'battle' })`，而是启动战斗状态后通知 `HomeView` 切换 `centerView = 'battle'`。

战斗结束后按来源恢复上下文：

- 野外战斗结束：回到地图视图。
- 单人副本楼层胜利：继续停留在战斗视图并显示楼层结算；点击下一层后刷新同一战斗台。
- 副本撤退或通关：回到副本视图。
- 多人副本结束或撤退：回到组队/房间相关视图。

移动端下，战斗视图优先占据主区域；左右角色和背包面板按现有响应式规则折叠或下移，不为战斗新增独立移动路由。

## 视觉设计

战场采用“焦点目标 + 两侧队列”：

- 当前选中目标或 Boss 位于中间焦点区域，尺寸更大，显示 HP、关键状态和阶段信息。
- 我方角色、战宠、队友以紧凑队列展示在左侧。
- 其他敌方单位以队列或小卡展示在右侧。
- 普通战斗使用同一结构，但中心目标尺寸更克制；Boss/精英战强化阶段、狂暴、复活等信息。

布局层级从上到下：

1. 战斗标题栏：回合数、来源场景、当前阶段、退出/撤退入口。
2. 行动顺序条：展示当前和后续行动单位。
3. 焦点战场：中心目标 + 两侧队列。
4. 行动区：普攻、技能、防御、逃跑/撤退等操作。
5. 战斗日志：默认底部紧凑流，不抢主战场视觉。
6. 结算层：战斗台内部弹层，不再覆盖整页路由。

所有样式遵守 `DESIGN.md` 的 Liquid Glass 设计变量，使用已有颜色、圆角、阴影、字体和玻璃质感，不引入新的设计 token。

## 组件结构

新增或调整前端组件：

- `BattleConsole.vue`：可内嵌战斗台容器，承接原 `BattleView.vue` 的战斗态 UI。
- `BattleFocusField.vue`：焦点目标 + 两侧队列战场组件。
- `BattleView.vue`：保留为兼容/调试入口时，可薄封装 `BattleConsole.vue`；主流程不再依赖它跳转。

复用现有组件：

- `ActionOrderBar.vue`
- `BattleActionPanel.vue`
- `BattleLog.vue`
- `BattleResultOverlay.vue`
- `DungeonFloorResultOverlay.vue`
- `BossPhaseIndicator.vue`
- `BossEnrageTimer.vue`
- `ReviveButton.vue`
- `CombatantBar.vue` 中可复用的血条与单位信息样式

## 数据流

`useBattleStore` 和 `useDungeonStore` 保持为战斗状态来源。

地图、副本、多人房间启动战斗后，通过事件向父层传递来源：

- `WorldMapPanel` 触发 `battle-started`，来源为 `map`。
- `DungeonPanel` 触发 `battle-started`，来源为 `dungeon`。
- `DungeonRoomPanel` 触发 `battle-started`，来源为 `team`。

`HomeView` 保存 `lastNonBattleView` 或 `battleReturnView`，用于战斗结束后恢复上下文。

## 错误处理

- 启动战斗失败时不切换到战斗视图，继续显示原页面 Toast。
- 战斗中缺少角色详情或战斗状态时，战斗台显示空态并提供返回来源视图。
- 副本结算失败时保留当前战斗结算层提示，不直接跳走。

## 测试计划

- 运行 `npm run build`。
- 检查首页 `/` 下野外战斗：地图触发战斗，中栏切换战斗台，结束后回地图。
- 检查单人副本：进入副本后中栏战斗，楼层胜利、下一层、撤退/结算路径可用。
- 检查多人副本房间：开始挑战后中栏战斗，队友/敌人排布可读。
- 检查 Boss/精英战：焦点目标、Boss 阶段、狂暴、复活按钮不互相遮挡。
- 检查 720px 以下：战斗台不横向溢出，行动按钮和日志不重叠。
