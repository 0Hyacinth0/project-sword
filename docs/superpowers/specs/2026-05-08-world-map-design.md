# 世界地图页面设计文档

## 概述

实现世界地图页面，以 Liquid Glass 卡片式布局展示游戏中的 4 个区域。玩家可查看区域解锁状态、怪物信息、掉落预览，点击已解锁区域展开详情面板后可进入探索或副本。

## 路由

- 路径：`/map`
- 需要认证，需要已选择角色

## 页面结构

自上而下：

1. **页面标题栏** — "世界地图" 标题 + 角色等级徽章（如 "Lv.24"）
2. **区域卡片列表** — 4 张 Liquid Glass 卡片纵向排列
3. **展开详情面板** — 点击已解锁区域后，卡片下方平滑展开

### 区域卡片视觉

遵循 DESIGN.md Liquid Glass 规范，每张卡片包含：
- 区域 emoji 图标（40px 圆角方块）
- 区域名称（14px 加粗）
- 等级范围（10px 次要色）
- 解锁状态标签

**卡片状态**：

| 状态 | 视觉表现 |
|:---|:---|
| 当前区域 | 橙色边框 + 橙色光晕，标签 "当前区域" |
| 已解锁 | 绿色标签 "已解锁"，正常毛玻璃效果 |
| 未解锁 | 半透明灰色，虚线边框，"🔒 需要 Lv.XX" |
| 未发现 | 完全模糊，只显示 "???" |

"当前区域"判定：角色等级在该区域的等级范围内。

### 展开详情面板

点击已解锁区域卡片后，该卡片下方平滑展开详情面板（max-height 过渡动画），包含：

1. **怪物列表** — 怪物名 + 等级，普通怪白色、精英怪紫色、Boss 橙色
2. **掉落预览** — 物品名 + 品质颜色（蓝/紫/橙）
3. **操作按钮**：
   - "进入探索"（主按钮，橙色）— 进入野外战斗
   - "副本"（次按钮，蓝色）— 进入副本选择

未解锁区域点击无响应。

## 数据模型

### 区域配置（静态数据）

```typescript
interface MapArea {
  id: string                  // 区域 ID
  name: string                // 区域名称
  icon: string                // emoji 图标
  levelRange: [number, number] // 等级范围 [min, max]
  description: string         // 区域描述
  monsters: AreaMonster[]     // 怪物列表
  drops: AreaDrop[]           // 掉落预览
  unlockLevel: number         // 解锁所需等级
}

interface AreaMonster {
  id: string
  name: string
  level: number
  type: 'normal' | 'elite' | 'boss'  // 普通/精英/Boss
}

interface AreaDrop {
  itemId: number
  name: string
  rarity: 'Rare' | 'Epic' | 'Legendary'  // 只展示稀有以上
}
```

### 4 个区域

| 区域 | 等级范围 | 解锁等级 | 怪物 |
|:---|:---:|:---:|:---|
| 迷雾森林 | 1-10 | 1 | 史莱姆、小精灵、森林蜘蛛 |
| 白骨荒野 | 11-20 | 11 | 骷髅、僵尸、骷髅将军(Boss) |
| 火焰山谷 | 21-30 | 21 | 火元素、炎魔、熔岩巨人(Boss) |
| 冰霜雪原 | 31-40 | 31 | 冰巨人、雪狼、霜龙(Boss) |

### 解锁规则

- 角色等级 >= 区域 `unlockLevel` 即解锁
- "未发现" 状态：下一级未解锁区域（如当前在迷雾森林，则火焰山谷和冰霜雪原为未发现）
- 只有已解锁且比当前区域高一级的区域可见名称，更高级区域显示 "???"
